# PPO Walkthrough (Bandit)

This walkthrough runs the PPO trainer on a simple bandit environment.

1) Set Tinyfin on PYTHONPATH:

```bash
export PYTHONPATH=/path/to/tinyfin/python
```

2) Run the PPO example:

```bash
python examples/ppo_bandit.py
```

3) Optional: save and resume:

```bash
python examples/ppo_checkpoint.py
```
